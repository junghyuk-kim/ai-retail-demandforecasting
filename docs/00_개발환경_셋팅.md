# 개발환경 셋팅

## 1. 프로그램 설치

1. **Python 3.10.6** — https://www.python.org/ftp/python/3.10.6/python-3.10.6-amd64.exe  
   - [설치·환경변수 가이드](https://m.blog.naver.com/math717/223984322849)
2. **Anaconda** (선택) — https://www.anaconda.com/download

## 2. 저장소·서브모듈

```bash
git clone https://github.com/junghyuk-kim/ai-retail-demandforecasting.git
cd ai-retail-demandforecasting
git submodule update --init --recursive
```

| submodule | 용도 |
|-----------|------|
| `vendor/Time-Series-Library` | DL — Autoformer, iTransformer (09장) |
| `vendor/ts2vec` | 시계열 임베딩 — TS2Vec (06·10장) |
| `vendor/PatchTST` | 시계열 임베딩 — PatchTST (06·10장) |
| `vendor/gaf-cnn` | 시계열 임베딩 — GAF-CNN (06·10장) |

## 3. Python 패키지

```bash
pip install -r requirements.txt
```

주요 의존성: `torch`, `neuralforecast`, `reformer-pytorch`(TSlib), `torchsummary`(gaf-cnn), `xgboost`, `optuna`, `pyarrow`, `fastdtw`, `pyts`

## 4. GPU (딥러닝 09장 · RTX 50 시리즈)

**RTX 5090/5080 등 Blackwell(sm_120)** 은 일반 `pip install torch`(CPU/cu124)로는 CUDA가 동작하지 않을 수 있습니다.

```bash
pip uninstall torch torchvision torchaudio -y
pip install --pre torch torchvision --index-url https://download.pytorch.org/whl/nightly/cu128 --no-cache-dir
```

확인:

```bash
python -c "import torch; print(torch.cuda.is_available(), torch.cuda.get_device_name(0))"
```

## 6. 노트북 실행 (선택)

```bash
cd code
python execute_notebook.py "06_클러스터링_방법.ipynb" 7200
python execute_notebook.py "09_딥러닝_예측모델.ipynb" 7200
```

- **09장** DL 재실험 → `phase1_dl_results.parquet` 삭제 후 실행
- **10장** 임베딩 변경 후 → `phase2_results.parquet` 삭제 후 실행

# 실험 프레임워크 (학위논문 · 책 실습)

## 1. SBC 4분류

SBC(Syntetos–Boylan Classification)는 ADI·CV²로 수요를 4유형으로 나눕니다.

| 클러스터 | 조건 | 해석 |
|----------|------|------|
| Smooth | ADI<1.32, CV²<0.49 | 연속·안정 |
| Intermittent | ADI≥1.32, CV²<0.49 | 간헐·저변동 |
| Erratic | ADI<1.32, CV²≥0.49 | 연속·고변동 |
| Lumpy | ADI≥1.32, CV²≥0.49 | 간헐·고변동 |

임계값 1.32/0.49는 학위논문 원본과 동일. SBC 라벨은 해석·세분화 축이며 **실측 Best를 보장하지 않습니다.**

## 2. 논문 vs 본 저장소 실습 (2-type 축소)

| 항목 | 학위논문(국내 소매업체) | 본 저장소(Ecuador) |
|------|-------------|--------------------|
| 데이터 | 12,661 SKU · 2센터 · 156주 | **66 시계열**(2-type E·C) · 242주 |
| 고/저변동 판별 | **System-Level CV/CV²**(SKU-Level은 센터 간 동일) | 동일 — **E**(CV 0.429, 고) · **C**(0.259, 저) |
| 분할 | train/val/test 3-way | **train 216주 / val 13주(튜닝) / test 13주(평가)** |
| DL lookback / 지평 | 긴 입력 | **26 / 13주** |
| 정규화 | Min-Max(forecasting), StandardScaler(clustering) | 동일 |
| 튜닝 | Optuna TPE, val RMSE, 클러스터 대표평균 | Optuna TPE, val RMSE, **조건 패널 직접**(소규모) |
| Phase1 Best 지표 | MAPE/WMAPE | **MAPE** |
| Phase2 base | **iTransformer** + 임베딩 | **LSTM** + 임베딩(neuralforecast static exog) |
| scheme 비교 WMAPE | Σ n_k·MAPE_k/Σ n_k | 동일(`thesis_wmape_by_type`) |

### 결론이 갈리는 지점 — 표본 규모의 귀결

학위논문은 국내 소매업체 물류센터의 **비공개 데이터**(연구 목적 한정)로 수행했고, 이 저장소는 독자가 재현할 수 있도록 의도적으로 **공개 데이터**로 같은 방법론을 다시 실행합니다. 규모 차이가 크므로 결론도 갈립니다.

| | 학위논문 | 본 실습 | 배율 |
|---|---|---|---|
| 계열 수 | 12,661 × 2센터 | **66** | 약 380배 |
| 총 레코드 | 약 395만 | 약 1.6만 | 약 247배 |
| 조건당 학습 계열 | 수백~1만 | **1~19**(중앙값 6) | — |

| 쟁점 | 학위논문 (대규모) | 본 실습 (소규모) |
|------|------------------|-----------------|
| 최적 알고리즘 | iTransformer 등 트랜스포머 SOTA | **10모델이 median 31~39로 촘촘** (조건별 승자 통계 7 / DL 3 / ML 2) |
| Phase2 base | iTransformer + 임베딩 | **LSTM** + 임베딩 |
| scheme 대응 | 고변동→SBC · 저변동→ML | **양 type 모두 SBC 우세** |

**scheme 결론은 재현되지 않았습니다.** 본 실습에서는 C 38.18 vs 38.19(−0.01, 사실상 동률), E 46.72 vs 47.60(−0.88)로 양쪽 다 SBC가 앞섭니다. ML 군집이 30:3·31:2로 퇴화해 ML scheme이 세분화 이점을 내지 못한 것이 주된 원인입니다. 계열이 충분해야 ML 클러스터링이 의미 있는 군집을 만든다는 점을 역으로 보여줍니다.

> 같은 방법론·같은 공식 구현으로 두 데이터를 돌렸을 때 승자가 뒤바뀐다는 사실 자체가 실무적 발견입니다. **알고리즘의 절대적 우열은 없으며 데이터 규모가 선택을 좌우합니다.** 벤치마크 순위표보다 자기 데이터의 계열 폭을 먼저 확인해야 합니다.

## 3. 딥러닝 구현 (09장)

- Autoformer·iTransformer: [thuml/Time-Series-Library](https://github.com/thuml/Time-Series-Library) submodule의 `Model` 클래스를 `tslib_adapter.py`에서 호출 (단독 repo `run.py` 파이프라인 아님).
- N-HiTS·LSTM: [Nixtla/neuralforecast](https://github.com/Nixtla/neuralforecast).
- **열별 Min-Max 정규화 후 학습·예측**(역변환). iTransformer는 **Optuna(8 trials, lr·d_model·e_layers·dropout)** 로 val RMSE 튜닝.
- 조건(type×cluster) 단위 다변량 패널 1회 학습.

### 09장 결과 (계열 단위 MAPE)

| model | median | mean | | model | median | mean |
|-------|--------|------|-|-------|--------|------|
| SBA | **31.4** | 161.9 | | LSTM | 34.5 | **45.0** |
| N-HiTS | 32.7 | 98.6 | | TSB | 34.6 | 174.0 |
| ARIMA | 32.9 | **45.7** | | Prophet | 36.5 | 113.0 |
| **iTransformer** | **33.8** | 141.7 | | RF | 37.2 | 129.6 |
| XGBoost | 34.3 | 100.1 | | Autoformer | 39.4 | 134.9 |

**median은 31~39로 촘촘**합니다. 축소 데이터라 단순 모델도 경쟁적이며 iTransformer는 중위권(33.8)입니다.

**mean을 함께 보면 순위가 뒤집힙니다.** LSTM 45.0·ARIMA 45.7이 압도적이고, median 1위 SBA는 161.9, TSB 174.0, iTransformer 141.7로 폭발합니다. 즉 대부분 모델이 **일부 어려운 계열에서 크게 빗나가며**, 두 지표 모두 안정적인 것은 LSTM뿐입니다.

조건별 Phase1 승자(2-type × 4군집 × 2 scheme = 12조건)를 계층으로 묶으면:

| 계층 | 승리 조건 수 | 내역 |
|------|-------------|------|
| 통계 | **7** | ARIMA 5 · Prophet 2 |
| 딥러닝 | 3 | LSTM 2 · N-HiTS 1 |
| 머신러닝 | 2 | XGBoost 1 · RF 1 |

### 왜 딥러닝의 우위가 사라졌는가

학위논문에서 iTransformer가 SOTA였던 것과 달리 본 실습에서 중위권에 머무는 이유는 **알고리즘 구현이 아니라 학습 대상 규모**입니다.

주의할 점은 **딥러닝이 무너진 것은 아니라는 것**입니다. N-HiTS는 median 32.7로 전체 2위이고, iTransformer도 33.8로 XGBoost·LSTM·RF보다 앞섭니다. 다만 **논문에서 보였던 압도적 우위가 사라지고 통계 모델과 뒤섞였습니다**. 조건별 1위 횟수도 통계 7 vs 딥러닝 3으로 역전됩니다.

아래 세 가지가 함께 작용합니다.

**① 조건당 시계열 수가 1~19개뿐**

딥러닝은 조건(type×cluster) 단위로 여러 계열을 함께 학습하는 **global model** 구조입니다. 그런데 본 실습의 조건별 계열 수는 다음과 같습니다.

| SBC 유형 | 계열 수 (C / E) |
|----------|----------------|
| Smooth | 19 / 19 |
| Intermittent | 10 / 9 |
| Lumpy | 3 / 3 |
| **Erratic** | **1 / 2** |

중앙값 6개, 최소 1개입니다. Transformer·N-HiTS가 계열 간 공유 표현을 학습할 여지가 사실상 없습니다. 학위논문 실증은 **센터당 12,661 SKU**로, 계열 수가 약 3자릿수 더 많습니다.

**② 학습 단위에 따라 같은 데이터가 다르게 보인다**

- **딥러닝** — 조건 단위로 여러 계열을 함께 학습하므로 **계열 수가 곧 표본 수**입니다. 19계열, Erratic은 1~2계열입니다.
- **ARIMA·SBA·TSB·Prophet** — 계열마다 독립 추정하므로 계열 수와 무관합니다. 242주 길이만 있으면 되고, 그 길이는 충분합니다.
- **XGBoost·RF** — 관측치(행) 단위 학습기. Smooth 조건은 19계열 × 242주 ≈ **4,600행**입니다.

즉 같은 데이터가 딥러닝에는 "표본 19개", ARIMA에는 "길이 242주짜리 계열 19개", 트리 모델에는 "표본 4,600행"으로 보입니다. 계열 폭이 좁을수록 딥러닝만 불리해집니다.

**③ 계열 길이는 충분하나 폭이 부족**

242주는 단변량 통계 모델이 계절성과 간헐성을 추정하기에 넉넉합니다. ARIMA가 12개 조건 중 5개에서 1위를 한 이유입니다. 딥러닝의 강점은 계열 길이가 아니라 **계열 폭(다수 SKU의 공통 패턴)** 에서 나오는데, 그 폭이 없습니다.

**구현 자체는 정상입니다.** 공식 코드(thuml Time-Series-Library, Nixtla neuralforecast)를 사용했고, iTransformer는 Optuna로 튜닝했으며, LSTM·N-HiTS가 3개 조건에서 1위를 차지합니다. 10모델이 median 31~39 구간에 고르게 분포한다는 점도 특정 모델만 오작동한 것이 아님을 보여줍니다.

> **해석** — 이 결과는 알고리즘의 절대적 우열이 아니라 **데이터 규모에 따른 적합성**을 보여줍니다. 학위논문 실증(12,661 SKU·3년)처럼 계열 폭이 넓으면 대형 트랜스포머가 우위를 갖지만, 본 실습(66계열)처럼 좁으면 통계 모델과 뒤섞입니다. 실무에서 모델을 고를 때 "최신 SOTA"보다 **보유 데이터의 계열 폭**을 먼저 봐야 하는 이유입니다.

## 4. 시계열 임베딩·클러스터링 (06·10장)

- 임베딩 6종(PCA/FastDTW/AE/GAF-CNN/TS2Vec/PatchTST) × 클러스터링 4종 그리드.
- **균형 인지 선정**: 실루엣+DB에 **최소 클러스터 크기 ≥4** 조건을 추가해, outlier 1개만 떼는 degenerate 해를 배격(논문의 degenerate-solution 배격 대응).
- 축소 66 시계열은 K=2가 상한 → **TS2Vec+KMeans** 선정 (cluster2=메가셀러 5개, cluster1=롱테일 61개).
- **10장 Phase2**: base = **LSTM** + 임베딩(static exog).

  ARIMA가 Phase1 median MAPE 1위지만 **계열별 단변량 모델이라 임베딩 결합이 무의미**합니다. 임베딩은 계열당 하나인 정적 벡터라 단변량 모델에서는 절편에 흡수돼 정보를 주지 못하고, 여러 계열을 함께 학습하는 모델에서만 계열 구분자로 작동합니다. 따라서 임베딩 결합이 가능한 최상위인 **LSTM**(Phase1 2위)을 base로 고정합니다.

  **결합 가능한 모델 중에서는 LSTM이 가장 견고합니다.** ARIMA·SBA·TSB·Prophet을 제외하면 후보는 LSTM·N-HiTS·iTransformer·Autoformer·XGBoost·RF인데, mean MAPE로 보면 LSTM 45.0이 압도적입니다(N-HiTS 98.6 · XGBoost 100.1 · RF 129.6 · iTransformer 141.7). median으로는 N-HiTS(32.7)가 앞서지만 mean이 3배 가까이 크므로, **어려운 계열에서 무너지지 않는 쪽**을 base로 택합니다.

  임베딩 결합 효과는 median 34.5 → **34.0**, mean 45.0 → **44.3**(LSTM+GAF-CNN)입니다.

  | 임베딩 | median | mean |
  |--------|--------|------|
  | GAF-CNN | **34.0** | 44.3 |
  | PCA | 34.3 | 43.9 |
  | AE | 34.4 | 43.8 |
  | FastDTW | 34.5 | **43.5** |
  | PatchTST | 34.6 | 45.0 |
  | TS2Vec | 35.2 | 43.9 |

  6종이 median 34.0~35.2, mean 43.5~45.0으로 **근소차**입니다. 조건별 Best는 FastDTW 4 · AE 2 · GAF-CNN 2 · PatchTST 2 · TS2Vec 1 · PCA 1로 갈리며, 특정 임베딩이 일관되게 우세하지는 않습니다.

> **임베딩 품질 점검** — 임베딩 구현이 정상인지는 **군집 품질 지표가 서로 구별되는지**로 확인할 수 있습니다. 두 임베딩의 실루엣·DB 값이 소수점까지 같다면 내부 예외로 baseline(PCA)이 반환되고 있다는 신호입니다. 본 저장소는 6종이 모두 고유한 값을 갖습니다 — GAF-CNN 0.122 · TS2Vec 0.877 · PCA 0.801 등.

## 5. 노트북 흐름 (02–14)

```
02 전처리·2-type선정 → 03 피처 → 05 SBC → 06 ML클러스터링
→ 07 통계 → 08 ML → 09 DL → 10 임베딩 → 11 하이브리드 → 12 RIDR → 13 변수중요도 → 14 Optuna
```

- 07–09: Phase1 — **12조건**(2 type × [SBC 4 + ML 2]) × 10모델, 조건별 MAPE Best
- 10: Phase2 — **LSTM 고정 × 6임베딩** (72조합, 임베딩=static exog)
- 11: type별 **제품수 가중 WMAPE** SBC vs ML → **양 type 모두 SBC 우세** (C 38.18 vs 38.19 · E 46.72 vs 47.60)
- 12: CV·RIDR·수요 밴드 / 13–14: 변수 중요도·Optuna 튜닝

## 6. 해석 시 유의사항

1. **패턴 유형 ≠ 최적 알고리즘** — 선택은 실측 MAPE/WMAPE.
2. **논문 SOTA ≠ 축소 실습 Best** — iTransformer 강세는 12,661 SKU·3년의 대규모 맥락. 66 시계열에서는 10모델이 median 31~39로 촘촘하고 iTransformer는 **중위권(33.8)** 입니다.
3. **median과 mean을 함께 본다** — SBA는 median 31.4로 1위지만 mean은 161.9입니다. 전형적 계열에 강하고 어려운 계열에서 무너진다는 뜻으로, 두 지표 모두 안정적인 것은 LSTM(34.5 / 45.0)뿐입니다.
4. **SBC vs ML 우열은 데이터 규모에 의존** — 본 축소 실습(66계열)에서는 **양 type 모두 SBC 우세**로, 논문의 변동성↔scheme 대응(고변동→SBC·저변동→ML)이 재현되지 않았습니다. ML 군집이 30:3·31:2로 심하게 불균형해 ML scheme이 제 역할을 못 한 것이 주된 원인입니다. 대규모 데이터에서 이 대응이 성립하는지는 학위논문 실증을 참고하세요.
5. **MAPE는 near-zero 수요에서 불안정** — median·WMAPE 병행.
6. **단일 데이터셋** — 일반화 제한.

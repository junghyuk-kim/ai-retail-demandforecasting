# 실험 프레임워크

## 1. SBC 4분류

| 클러스터 | 조건 | 해석 |
|----------|------|------|
| Smooth | ADI<1.32, CV²<0.49 | 연속·안정 |
| Intermittent | ADI≥1.32, CV²<0.49 | 간헐·저변동 |
| Erratic | ADI<1.32, CV²≥0.49 | 연속·고변동 |
| Lumpy | ADI≥1.32, CV²≥0.49 | 간헐·고변동 |

임계값 1.32/0.49는 학위논문과 동일. 라벨은 세분화 축이며, 최적 알고리즘은 실측 MAPE/WMAPE로 고릅니다.

---

## 2. 논문 실증 vs 본 실습

| 항목 | 학위논문 | 본 실습 |
|------|----------|---------|
| 데이터 | 12,661 SKU · 2센터 · 156주 | **66** 시계열 (E·C) · 242주 |
| 고/저변동 | System-Level CV | E 0.429 · C 0.259 |
| 분할 | train/val/test | 216 / 13 / 13주 |
| lookback / 지평 | — | **26 / 13주** |
| Phase2 base | iTransformer + 임베딩 | **LSTM** + 임베딩 |
| scheme WMAPE | Σ n_k·MAPE_k / Σ n_k | 동일 |

표본이 작아(조건당 계열 1~19, 중앙값 6) 논문과 승자가 달라질 수 있습니다.

| 쟁점 | 논문 | 본 실습 |
|------|------|---------|
| 알고리즘 | iTransformer 강세 | median 31~39로 좁음, 조건별 승자 통계 7 / DL 3 / ML 2 |
| scheme | 고변동→SBC · 저변동→ML | **둘 다 SBC** (C 38.18 vs 38.19 · E 46.72 vs 47.60) |

ML 군집이 C 30:3 · E 31:2로 치우쳐, 저변동→ML 가설은 이 데이터에서 확인되지 않았습니다. type 간 CV 차이(0.259 vs 0.429)도 논문·다이소 실증만큼 크지 않습니다.

## 3. Phase1 결과 (계열 단위 MAPE)

| model | median | mean | model | median | mean |
|-------|--------|------|-------|--------|------|
| SBA | **31.4** | 161.9 | LSTM | 34.5 | **45.0** |
| N-HiTS | 32.7 | 98.6 | TSB | 34.6 | 174.0 |
| ARIMA | 32.9 | **45.7** | Prophet | 36.5 | 113.0 |
| iTransformer | 33.8 | 141.7 | RF | 37.2 | 129.6 |
| XGBoost | 34.3 | 100.1 | Autoformer | 39.4 | 134.9 |

median만 보면 SBA가 앞서고, mean까지 보면 LSTM·ARIMA가 안정적입니다. 조건당 계열이 적으면 트랜스포머의 계열 간 공유 학습 여지가 줄어듭니다.

**구현:** Autoformer·iTransformer → [Time-Series-Library](https://github.com/thuml/Time-Series-Library) (`tslib_adapter.py`). N-HiTS·LSTM → [neuralforecast](https://github.com/Nixtla/neuralforecast). Min-Max 정규화, iTransformer는 Optuna(val RMSE).

## 4. 임베딩·클러스터링 · Phase2

- 6 임베딩 × 4 클러스터링. 실루엣·DB + **min cluster size ≥ 4** (degenerate 해 제외).
- 채택: **TS2Vec+KMeans, K=2** → [61, 5] (롱테일 / 메가셀러).

6종 차이는 작습니다. 조건별 Best: FastDTW 4 · AE 2 · GAF-CNN 2 · PatchTST 2 · TS2Vec 1 · PCA 1.

## 6. 해석 시

1. SBC 라벨 ≠ 최적 알고리즘 — 실측 지표로 선택.
2. 논문과 승자가 다를 수 있음 — 표본·변동 스펙트럼 차이.
3. MAPE는 near-zero 수요에서 불안정 — median·WMAPE를 함께 봄.
4. Ecuador 2-type 결과의 일반화는 제한적.

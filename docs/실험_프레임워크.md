# 실험 프레임워크 (학위논문 · 책 실습)

## 1. SBC 4분류의 의미

SBC(Syntetos-Boylan Classification)는 ADI·CV² 기준으로 수요 패턴을 **4유형**으로 나눕니다.

| 클러스터 | 조건 | 이론적 해석 |
|----------|------|-------------|
| Smooth | ADI<1.32, CV²<0.49 | 연속·안정 수요 |
| Intermittent | ADI≥1.32, CV²<0.49 | 간헐·저변동 |
| Erratic | ADI<1.32, CV²≥0.49 | 연속·고변동 |
| Lumpy | ADI≥1.32, CV²≥0.49 | 간헐·고변동 |

**중요:** Smooth→ARIMA, Intermittent→SBA/TSB 등 **패턴별 적합 알고리즘**은 문헌상 *이론적 권고*일 뿐, **실증적 SOTA를 보장하지 않습니다.**

학위논문 실험에서는 **시계열 임베딩 여부와 관계없이 iTransformer가 전 클러스터에서 최고 성능**을 보였습니다.

## 2. 논문 전체 실험 설계 (10개 알고리즘)

### 예측 알고리즘 (10종)
ARIMA, Prophet, SBA, TSB, RF, XGBoost, LSTM, Autoformer, N-HiTS, **iTransformer**

### Phase 1 — 클러스터·type별 단일 알고리즘 벤치마크
- **SBC**: 4 clusters × 5 types = **20 실험 조건**
- **ML 클러스터링**: 동일하게 type×cluster 조건별 실험
- 각 조건에서 **10개 알고리즘을 모두 1회** 실행 → WMAPE 비교 → **조건별 Top 알고리즘** 선정

### Phase 2 — 임베딩 하이브리드
- Phase 1 Top 알고리즘에 **6종 시계열 임베딩** 결합
  - PCA, DTW, AutoEncoder, GAF-CNN, TS2Vec, **PatchTST**
- 임베딩 + 예측으로 **2차 예측** 수행 후 WMAPE 재비교

### 비교 축
- **클러스터링**: SBC (rule-based) vs ML (비지도 학습)
- **매장 type**: Ecuador 데이터에서 논문의 센터 A/B → **type 5종** (D, B, C, E, A)
- **지표**: WMAPE (주 지표)

## 3. 본 저장소 실습 범위 (경량화)

전체 20조건 × 10알고리즘 × Phase 2 임베딩은 연산량이 큽니다.  
실습에서는 아래 **축소 설계**로 핵심 결론을 재현합니다.

| 단계 | 내용 |
|------|------|
| 05~06 | SBC / ML 클러스터링 |
| 07~08 | 10알고리즘 중 일부 전역 벤치마크 (type×family 165 시계열) |
| 09 | DL 4종 — **thuml Time-Series-Library**(Autoformer·iTransformer) + **neuralforecast**(N-HiTS·LSTM) |
| 10 | **PatchTST 임베딩 + iTransformer** 로 SBC vs ML 하이브리드 WMAPE 비교 |

**목표:** type(5) × cluster(4) 단위 WMAPE로 **어떤 클러스터링·예측 조합이 유리한지** 빠르게 확인.

> 현재 10장 노트북의 `CLUSTER_MODEL` 매핑( Smooth→ARIMA 등)은 **이론적 예시**이며, 논문 결론(SOTA=iTransformer)과 동일하지 않습니다.

## 4. 해석 시 유의사항

1. **패턴 유형 ≠ 최적 알고리즘** — SBC 라벨은 세분화·해석용, 알고리즘 선택은 **실측 WMAPE**로 결정
2. **전역 평균 vs 클러스터별** — 07·08장 전체 평균은 클러스터별 Top과 다를 수 있음
3. **임베딩 효과** — 논문에서 iTransformer 단독·임베딩 결합 모두 강세 → Phase 2에서 재검증 필요

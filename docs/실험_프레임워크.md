# 실험 프레임워크 (학위논문 · 책 실습)

## 1. SBC 4분류의 의미

SBC(Syntetos-Boylan Classification)는 ADI·CV² 기준으로 수요 패턴을 **4유형**으로 나눕니다.

| 클러스터 | 조건 | 이론적 해석 |
|----------|------|-------------|
| Smooth | ADI<1.32, CV²<0.49 | 연속·안정 수요 |
| Intermittent | ADI≥1.32, CV²<0.49 | 간헐·저변동 |
| Erratic | ADI<1.32, CV²≥0.49 | 연속·고변동 |
| Lumpy | ADI≥1.32, CV²≥0.49 | 간헐·고변동 |

**중요:** Smooth→ARIMA, Intermittent→SBA/TSB 등 **패턴별 적합 알고리즘**은 문헌상 *이론적 권고*일 뿐, **실측 Best를 보장하지 않습니다.**

## 2. 논문 vs 본 저장소 실습

### 논문(학위연구)에서의 주요 결론

- **10종 알고리즘** 벤치마크: ARIMA, Prophet, SBA, TSB, RF, XGBoost, LSTM, Autoformer, N-HiTS, **iTransformer**
- Phase 1: type×cluster 조건별 **WMAPE**로 Best 선정
- Phase 2: Best 모델 + **6종 임베딩** 하이브리드
- **iTransformer**가 (임베딩 여부와 관계없이) 많은 조건에서 최고 성능을 보고한 바 있음

### 본 저장소(Ecuador 실습)와의 차이 — **결론이 달라질 수 있음**

| 항목 | 논문 | 본 저장소 실습 |
|------|------|----------------|
| 데이터 | 연구용 소매 데이터 | Ecuador Favorita **165 주간** 시계열 |
| 검증 | 연구 설계 | **3주** (`201731–201733`) |
| DL lookback | 긴 입력(예: 96+) | **16주** |
| DL variate 수 | 수백 개 수준 다변량 | 조건당 family **~5–15개** |
| Phase1 Best 지표 | WMAPE | **MAPE** |
| Phase2 base | 조건별 Best | **XGBoost 고정** (실험 수 축소) |
| XGBoost | 피처 기반 ML | lag·rolling 등 **03장 피처** → 13장에서 lag_1 압도적 |

**따라서 Ecuador 실습에서 XGBoost가 DL보다 자주 Best인 것은 오류가 아니라, 데이터·지표·설정이 논문과 다르기 때문입니다.**

## 3. 딥러닝 구현 (09장)

### 사용하는 공식 코드

| 모델 | 연결 방식 | 비고 |
|------|-----------|------|
| Autoformer, iTransformer | [thuml/Time-Series-Library](https://github.com/thuml/Time-Series-Library) **git submodule** | `models/Autoformer.py`, `models/iTransformer.py`의 `Model` 클래스 |
| N-HiTS, LSTM | [Nixtla/neuralforecast](https://github.com/Nixtla/neuralforecast) **pip 패키지** | 공식 `NHITS`, `LSTM` |

> 단독 repo [`thuml/Autoformer`](https://github.com/thuml/Autoformer), [`thuml/iTransformer`](https://github.com/thuml/iTransformer)의 `run.py`를 그대로 실행하는 구조는 **아닙니다.** thuml이 통합 배포하는 Time-Series-Library의 모델 코드를 `code/utils/tslib_adapter.py`에서 호출합니다.

### 학습 방식 (Lite stub 제거 후)

- **조건(type×cluster) 단위 다변량 패널** 1회 학습 → 해당 조건 내 family별 예측 분배
- 어댑터: `dl_models.py` → `tslib_adapter.py` / `neuralforecast_adapter.py`
- 공식 repo의 ETT 벤치마크 스크립트와 **하이퍼파라미터·데이터 형식은 다름** (Ecuador 주간 데이터에 맞춘 설정)

### 09장 재실행 결과 예시 (평균 MAPE)

| model | ML | SBC |
|-------|-----|-----|
| N-HiTS | 119 | 122 |
| iTransformer | 151 | 137 |
| LSTM | 131 | 136 |
| Autoformer | 250 | 315 |

→ Phase1 **10모델 통합 Best**에서는 **XGBoost가 가장 자주** 선택됨 (08장 Phase1 merge 기준).

## 5. 해석 시 유의사항

1. **패턴 유형 ≠ 최적 알고리즘** — SBC 라벨은 해석·세분화 축, 선택은 **실측 MAPE/WMAPE**
2. **논문 SOTA ≠ 실습 Best** — iTransformer 강세는 **다변량·장기 예측** 맥락; Ecuador 3주·소수 variate에서는 XGBoost가 유리할 수 있음
3. **조건별 Best ≠ 전역 1위** — type×cluster마다 최적 모델이 다름
4. **scheme 비교(11장)** — WMAPE만 사용; Phase1 Best 선정은 MAPE
5. **단일 데이터셋** — Ecuador 5 type 결과의 일반화는 제한적

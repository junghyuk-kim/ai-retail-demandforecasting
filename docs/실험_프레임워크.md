# 실험 프레임워크 (학위논문 · 책 실습)

## 1. SBC 4분류

SBC(Syntetos–Boylan Classification)는 ADI·CV²로 수요를 4유형으로 나눕니다.

| 클러스터 | 조건 | 해석 |
|----------|------|------|
| Smooth | ADI<1.32, CV²<0.49 | 연속·안정 |
| Intermittent | ADI≥1.32, CV²<0.49 | 간헐·저변동 |
| Erratic | ADI<1.32, CV²≥0.49 | 연속·고변동 |
| Lumpy | ADI≥1.32, CV²≥0.49 | 간헐·고변동 |

임계값 1.32/0.49는 논문·Daiso 원본과 동일. SBC 라벨은 해석·세분화 축이며 **실측 Best를 보장하지 않습니다.**

## 2. 논문 vs 본 저장소 실습 (2-type 축소)

| 항목 | 논문(Daiso) | 본 저장소(Ecuador) |
|------|-------------|--------------------|
| 데이터 | 12,661 SKU · 2센터 · 156주 | **66 시계열**(2-type E·C) · 242주 |
| 고/저변동 판별 | **System-Level CV/CV²**(SKU-Level은 센터 간 동일) | 동일 — **E**(CV 0.429, 고) · **C**(0.259, 저) |
| 분할 | train/val/test 3-way | **train 216주 / val 13주(튜닝) / test 13주(평가)** |
| DL lookback / 지평 | 긴 입력 | **26 / 13주** |
| 정규화 | Min-Max(forecasting), StandardScaler(clustering) | 동일 |
| 튜닝 | Optuna TPE, val RMSE, 클러스터 대표평균 | Optuna TPE, val RMSE, **조건 패널 직접**(소규모) |
| Phase1 Best 지표 | MAPE/WMAPE | **MAPE** |
| Phase2 base | **iTransformer** + 임베딩 | **LSTM** + 임베딩(neuralforecast static exog) |
| scheme 비교 WMAPE | Σ n_k·MAPE_k/Σ n_k | 동일(`thesis_wmape_by_type`) |

**핵심:** Phase2 base로 **LSTM + 임베딩(static exog)** 을 쓰면, 본 축소 실습에서도 **저변동 C→ML, 고변동 E→SBC**로 논문(저변동 센터 A→ML, 고변동 센터 B→SBC) 방향과 **일치**합니다(격차 <1 WMAPE로 작음). 저변동은 ML 임베딩 군집, 고변동은 SBC 규칙 분류가 유리하다는 상호보완 구조가 방향성으로 재현됩니다.

## 3. 딥러닝 구현 (09장)

- Autoformer·iTransformer: [thuml/Time-Series-Library](https://github.com/thuml/Time-Series-Library) submodule의 `Model` 클래스를 `tslib_adapter.py`에서 호출 (단독 repo `run.py` 파이프라인 아님).
- N-HiTS·LSTM: [Nixtla/neuralforecast](https://github.com/Nixtla/neuralforecast).
- **열별 Min-Max 정규화 후 학습·예측**(역변환). iTransformer는 **Optuna(8 trials, lr·d_model·e_layers·dropout)** 로 val RMSE 튜닝.
- 조건(type×cluster) 단위 다변량 패널 1회 학습.

### 왜 트랜스포머 계열이 이 데이터에서 밀렸는가

학위논문에서 iTransformer가 SOTA였던 것과 결과가 뒤집힌 이유는 **알고리즘 구현이 아니라 학습 대상 규모**입니다.

주의할 점은 **딥러닝 전체가 밀린 것이 아니라는 것**입니다. LSTM은 median MAPE 42.6으로 전체 2위이고 2개 조건에서 1위를 차지했으며, N-HiTS도 46.4로 XGBoost·RF보다 앞섭니다. 밀린 것은 **어텐션 기반 트랜스포머 계열**입니다 — iTransformer 51.6(8위), Autoformer 73.1(10위)로 두 모델만 하위권입니다.

즉 정확한 진단은 *"딥러닝 < 머신러닝"* 이 아니라 **"파라미터가 많은 트랜스포머는 소표본에서 학습이 안 된다"** 입니다. LSTM·N-HiTS는 상대적으로 파라미터가 적고 구조가 단순해 66계열로도 버팁니다.

아래 세 가지가 함께 작용합니다.

**① 조건당 시계열 수가 1~19개뿐**

딥러닝은 조건(type×cluster) 단위로 여러 계열을 함께 학습하는 **global model** 구조입니다. 그런데 본 실습의 조건별 계열 수는 다음과 같습니다.

| SBC 유형 | 계열 수 (C / E) |
|----------|----------------|
| Smooth | 19 / 19 |
| Intermittent | 10 / 9 |
| Lumpy | 3 / 3 |
| **Erratic** | **1 / 2** |

중앙값 6개, 최소 1개입니다. Transformer·N-HiTS가 계열 간 공유 표현을 학습할 여지가 사실상 없습니다. 학위논문 실증은 **센터당 12,661 SKU**로, 계열 수가 약 3자릿수 더 많습니다.

**② 모델 복잡도와 표본 수의 불균형**

딥러닝은 조건 단위로 여러 계열을 함께 학습하므로 **계열 수가 곧 표본 수**입니다.

- **트랜스포머(iTransformer·Autoformer)** — 어텐션 파라미터가 많아 19계열로는 과적합·미수렴을 피하기 어렵습니다.
- **LSTM·N-HiTS** — 파라미터가 적고 구조가 단순해 같은 조건에서도 버팁니다. 실제로 상위권입니다.
- **ARIMA·SBA** — 계열마다 독립 추정하므로 계열 수와 무관합니다. 242주 길이만 있으면 되고, 그 길이는 충분합니다.
- **XGBoost·RF** — 관측치(행) 단위 학습기. Smooth 조건은 19계열 × 242주 ≈ **4,600행**이라 학습은 되지만, 계열 간 공통 구조를 명시적으로 쓰지 못해 중위권에 머뭅니다.

즉 같은 데이터가 트랜스포머에는 "표본 19개", ARIMA에는 "길이 242주짜리 계열 19개", 트리 모델에는 "표본 4,600행"으로 보입니다.

**③ 계열 길이는 충분하나 폭이 부족**

242주는 단변량 통계 모델이 계절성과 간헐성을 추정하기에 넉넉합니다. ARIMA가 12개 조건 중 5개에서 1위를 한 이유입니다. 딥러닝의 강점은 계열 길이가 아니라 **계열 폭(다수 SKU의 공통 패턴)** 에서 나오는데, 그 폭이 없습니다.

**구현 자체는 정상입니다.** 공식 코드(thuml Time-Series-Library, Nixtla neuralforecast)를 사용했고, iTransformer는 Optuna로 튜닝했으며, LSTM·N-HiTS가 3개 조건에서 1위를 차지합니다. 성능 저하가 딥러닝 전체가 아니라 **파라미터가 많은 트랜스포머 두 모델에만 집중**된다는 점이 구현 오류가 아닌 구조적 요인임을 뒷받침합니다.

> **해석** — 이 결과는 알고리즘의 절대적 우열이 아니라 **데이터 규모에 따른 적합성**을 보여줍니다. 학위논문 실증(12,661 SKU·3년)처럼 계열 폭이 넓으면 iTransformer 같은 대형 트랜스포머가 SOTA가 되지만, 본 실습(66계열)처럼 좁으면 ARIMA·LSTM 같은 단순 구조가 더 견고합니다. 실무에서 모델을 고를 때 "최신 SOTA"보다 **보유 데이터의 계열 폭**을 먼저 봐야 하는 이유입니다.

## 4. 시계열 임베딩·클러스터링 (06·10장)

- 임베딩 6종(PCA/FastDTW/AE/GAF-CNN/TS2Vec/PatchTST) × 클러스터링 4종 그리드.
- **균형 인지 선정**: 실루엣+DB에 **최소 클러스터 크기 ≥4** 조건을 추가해, outlier 1개만 떼는 degenerate 해를 배격(논문의 degenerate-solution 배격 대응).
- 축소 66 시계열은 K=2가 상한 → **TS2Vec+KMeans** 선정 (cluster1=메가셀러, cluster2=롱테일).
- **10장 Phase2**: base = **LSTM** + 임베딩(static exog).

  ARIMA가 Phase1 median MAPE 1위지만 **계열별 단변량 모델이라 임베딩 결합이 무의미**합니다. 임베딩은 계열당 하나인 정적 벡터라 단변량 모델에서는 절편에 흡수돼 정보를 주지 못하고, 여러 계열을 함께 학습하는 모델에서만 계열 구분자로 작동합니다. 따라서 임베딩 결합이 가능한 최상위인 **LSTM**(Phase1 2위)을 base로 고정합니다.

  **그리고 그 선택이 실측으로 정당화됩니다.** median MAPE는 ARIMA 41.71 → LSTM 단일 42.58 → **LSTM+임베딩 41.66**으로, 임베딩 결합 후 ARIMA를 앞서며 12조건 중 **7조건**에서 우세합니다. 조건별로 보면 성격이 뚜렷합니다.

  | 조건 | ARIMA | LSTM+임베딩(최적) | 차이 |
  |------|-------|------------------|------|
  | SBC C-4 (Lumpy) | **247.05** | 44.14 (LSTM+PCA) | −202.91 |
  | SBC C-3 (Erratic) | 84.37 | 34.83 (LSTM+FastDTW) | −49.53 |
  | SBC E-3 (Erratic) | 67.44 | 44.78 (LSTM+PatchTST) | −22.66 |
  | SBC C-2 (Intermittent) | **28.71** | 36.20 | +7.49 |
  | SBC E-2 (Intermittent) | **40.66** | 51.33 | +10.68 |

  ARIMA는 안정적 계열에서 강하지만 **Erratic·Lumpy에서 MAPE가 84~247로 폭발**해 실무 적용이 어렵습니다. ARIMA의 median 1위는 안정 계열에서 벌어놓은 결과이고, LSTM+임베딩은 어려운 구간에서 훨씬 견고합니다. 재고·발주 의사결정에서는 최악 구간의 오차가 비용을 좌우하므로 **base를 LSTM으로 두는 것이 타당**합니다.

  임베딩별 median MAPE는 근소차입니다 — PCA 41.91 · AE 42.10 · PatchTST 42.53 · TS2Vec 42.79 · FastDTW 42.88 · GAF-CNN 43.14. 조건별 Best는 FastDTW 4 · AE 2 · GAF-CNN 2 · PatchTST 2 · TS2Vec 1 · PCA 1.

## 5. 노트북 흐름 (02–14)

```
02 전처리·2-type선정 → 03 피처 → 05 SBC → 06 ML클러스터링
→ 07 통계 → 08 ML → 09 DL → 10 임베딩 → 11 하이브리드 → 12 RIDR → 13 변수중요도 → 14 Optuna
```

- 07–09: Phase1 — **12조건**(2 type × [SBC 4 + ML 2]) × 10모델, 조건별 MAPE Best
- 10: Phase2 — **LSTM 고정 × 6임베딩** (72조합, 임베딩=static exog)
- 11: type별 **제품수 가중 WMAPE** SBC vs ML → **C(저변동)→ML, E(고변동)→SBC** (논문 방향 일치, 격차 작음)
- 12: CV·RIDR·수요 밴드 / 13–14: 변수 중요도·Optuna 튜닝

## 6. 해석 시 유의사항

1. **패턴 유형 ≠ 최적 알고리즘** — 선택은 실측 MAPE/WMAPE.
2. **논문 SOTA ≠ 축소 실습 Best** — iTransformer 강세는 12,661 SKU·3년의 대규모 맥락. 66 시계열에서는 하위권(51.6, 8위)이고 ARIMA(41.7)·LSTM(42.6)이 앞섭니다. 밀린 것은 딥러닝 전체가 아니라 파라미터가 많은 **트랜스포머 계열**입니다.
3. **SBC vs ML 우열은 데이터 규모에 의존** — 본 축소 실습(66계열)에서는 **양 type 모두 SBC 우세**로, 논문의 변동성↔scheme 대응(고변동→SBC·저변동→ML)이 재현되지 않았습니다. ML 군집이 30:3·31:2로 심하게 불균형해 ML scheme이 제 역할을 못 한 것이 주된 원인입니다. 대규모 데이터에서 이 대응이 성립하는지는 학위논문 실증을 참고하세요.
4. **MAPE는 near-zero 수요에서 불안정** — median·WMAPE 병행.
5. **단일 데이터셋** — 일반화 제한.
